# プロジェクトビジョン

## 1. ビジョンステートメント

このプロジェクトは、

> 日々の活動や興味を「観察」し、そこから生まれた小さな好奇心を自律的なエージェントが「調査・深掘り」して知識として蓄積・提示することで、
> ユーザー自身の学習と行動のサイクル（Observation → Reflection → Research → Expression）を加速させる「第二の脳」

を実現することを目指す。

## 2. 対象ユーザー・対象領域

- **対象ユーザー**:
  - 自分自身（技術・論文・食・イベントなどに幅広い興味を持つ個人開発者）
- **対象領域**:
  - **技術・論文**: 最新の LLM トレンド、アーキテクチャパターン、未読の論文
  - **食**: 気になる店、料理、レシピ
  - **イベント・体験**: 珍しいイベント、展示会、旅行先
  - **メタ（自己観察）**: 自分の興味の推移、活動ログ

## 3. 解決したい課題

- **情報の散逸と忘却**:
  - Misskey やブラウザで「これ面白いな」と思っても、その瞬間だけで終わり、後から振り返れない。
  - 積読や「あとで読む」が溜まる一方で、消化できない。
- **行動への未転換**:
  - 「なんとなく気になった」ものが、具体的な調査や行動（試してみる、行ってみる）に繋がらないまま流れてしまう。

## 4. 提供したい価値・ユースケース

- **自律的な知識循環**:
  - ユーザーが寝ている間にエージェントが「最近これに興味ありそうですね」と察知し、関連情報をまとめておいてくれる。
- **快適な振り返り体験**:
  - PC / スマホから、過去のレポートを「雑誌をめくるように」パラパラと読める（GitLab Pages + MkDocs）。
- **興味の可視化**:
  - 「今週の自分はこれにハマっていた」「昔はこれが好きだった」が一目でわかる。

## 5. 基本方針・前提

- **Markdown 正本主義**:
  - すべての知識は Markdown ファイルとして Git リポジトリで管理し、特定のツールにロックインされない。
- **既存エコシステムの活用**:
  - 閲覧には MkDocs (Material for MkDocs) を使い、検索や UI は既存のプラグインを最大限活用する。
- **プライベート運用**:
  - 外部公開を前提とせず、個人的なメモやログを安心して蓄積できる環境にする。
- **将来的な拡張**:
  - タグ・メタ情報による高度な検索や、ベクトル検索による「関連ノートの提示」を行う。

## 6. スコープ / 非スコープ（当面）

- **スコープ**:
  - 個人（シングルユーザー）が自分の興味・行動を振り返るための機能。
  - Misskey / Web からの情報収集と、Markdown レポートの生成・公開。
- **非スコープ**:
  - マルチユーザー SaaS としての提供。
  - 汎用的な SNS クライアント機能（投稿やリプライなど、エージェント活動に関係ないもの）。
  - リアルタイムなチャットボット（あくまで「レポート」という非同期な媒体を中心にする）。

## 7. 成功イメージ

- **「気づきの外部化」**:
  - 数ヶ月後に「この技術、Kamojiros が拾ってくれなかったら絶対スルーしてたな」という体験が生まれること。
- **「楽しみな日課」**:
  - 毎朝（あるいは毎週末）、エージェントが書いたレポートを読むのが楽しみになっていること。
- **「行動の変容」**:
  - レポートを読んで実際に新しい技術を試したり、紹介された店に行ったりする回数が増えること。
